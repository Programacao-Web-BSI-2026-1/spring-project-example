                    🏷️ 2. Mapeamento Objeto-Relacional com Anotações JPA
                

                

                    A JPA (Jakarta Persistence API) ensina ao Spring Boot como traduzir uma classe Java (Atributos e Tipos) em uma tabela de banco de dados relacional (Colunas, Chaves Primárias e Restrições DDL).
                

            


            
            

                
                

                    

                        br.edu.iff.ccc.entities.Produto.java
                        Clique nas linhas destacadas 💡
                    

                    
@Entity
@Table(name = "tb_produto")
public class Produto {

    @Id
    @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;

    @Column(name = "nm_produto", nullable = false, unique = true, length = 100)
    private String nome;

    @Column(name = "ds_descricao", nullable = false)
    private String descricao;

    // ⚠️ Construtor vazio OBRIGATÓRIO do JPA
    public Produto() {}

    public Produto(String nome, String descricao) {
        this.nome = nome;
        this.descricao = descricao;
    }
}

                    🧪 4. Testes Automatizados com `@DataJpaTest`
                

                

                    A anotação @DataJpaTest sobe um contexto super leve contendo apenas o banco H2 e as entidades JPA. Cada método de teste é isolado e executa um Rollback automático ao final, garantindo que o banco não fique desorganizado para os próximos testes.
                

            


            
            

                
                

                    

                        
Suíte de Testes do Repositório

                        
                    


                    

                        

                            

                                deveSalvarProdutoEGerarId()
                                PENDENTE
                            

                            
Verifica se o UUID é gerado e retornado com sucesso.

                        


                        

                            

                                deveLancarExcecaoQuandoNomeDuplicado()
                                PENDENTE
                            

                            
Verifica se unique = true lança DataIntegrityViolationException.
